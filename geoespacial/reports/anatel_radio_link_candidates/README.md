# Candidatos cadastrais de radioenlace

Os 928 grupos família--Fistel--ato foram particionados sem criar arestas: 175
possuem uma coordenada, 373 possuem mais de duas e são ambíguos, 40 possuem duas
coordenadas sem reciprocidade espectral e 340 possuem duas coordenadas com ao
menos uma frequência Tx/Rx recíproca. Os 340 permanecem candidatos; azimute,
distância, terreno e visada ainda precisam ser validados. O estado global é
`pairing_status: not_performed`.
